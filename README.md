# AirBnB Clone - Web Static

This repository contains the HTML and CSS implementations for the **AirBnB clone (web_static)** project at Holberton School / Software Engineering training. The project focuses on building a static web interface mimicking the core layout, styling, zoning, and search filtering of AirBnB.

## Project Structure & Files

The project is structured inside the `web_static` directory across progressive tasks:

* **Task 0 (`0-index.html`):** Basic HTML page with inline styling for header and footer.
* **Task 1 (`1-index.html`):** HTML page using internal `<style>` tags in the head section.
* **Task 2 (`2-index.html` & `styles/2-*.css`):** Modular CSS implementation using 3 separate CSS files (`2-common.css`, `2-header.css`, `2-footer.css`).
* **Task 3 (`3-index.html` & `styles/3-*.css`):** Enhanced zoning, typography (`Circular`, `Helvetica Neue`), and border layouts.
* **Task 4 (`4-index.html` & `styles/4-*.css`):** Added container elements, filter section components, and an interactive search button with hover opacity changes.
* **`images/` Directory:** Folder containing visual assets used across the web pages.

## Technologies Used
* **HTML5** for semantic markup.
* **CSS3** for layout styling, Flexbox, and responsive design.
* **Git & GitHub** for version control and remote storage.
